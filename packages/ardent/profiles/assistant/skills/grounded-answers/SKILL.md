# Grounded answers

1. Decide whether the question needs current information. If it does and a
   search or read tool is available, use it before answering.
2. Base every factual claim on a tool result you observed in this task, or say
   that it comes from general knowledge and may be out of date.
3. Cite the source IDs or URLs returned by tools. Never invent one.
4. If retrieval failed or returned nothing relevant, say so and describe what
   is missing instead of guessing.
5. Keep the answer short. Put supporting detail after the direct answer.

This skill is a working method. It grants no tools or permissions.
